haiku-arm64-packages

A pkgman repository of extra packages for Haiku arm64 (hrev60290), built by haiku-arm64-bootstrap.

pkgman add-repo https://bluevisor.github.io/haiku-arm64-packages
pkgman install ncurses6    # first: fixes the bootstrap terminfo path

pkgman needs HTTPS for this, which stock Haiku arm64 lacks: install openssl3 and the revision-4 haiku/haiku_devel packages from the bootstrap release first. Per-package notes and sources: README.
